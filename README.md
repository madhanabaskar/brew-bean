☕ Brew Bean


Brew Bean is a modern, responsive web application for a premium coffee shop and restaurant. Built with performance and beautiful aesthetics in mind, it provides customers with an intuitive interface to browse the menu, view the gallery, make reservations, and contact the shop.

<img width="1920" height="1080" alt="Brew Bean Preview" src="https://github.com/user-attachments/assets/797b4958-815e-4563-b381-67c5b730d3d0" />

## ✨ Features

- **Modern UI/UX**: Designed with sleek aesthetics, smooth animations, and a responsive layout for all devices.
- **Dynamic Routing**: Seamless client-side navigation using React Router.
- **Interactive Menu**: Browse coffee, pastries, and meals easily.
- **Table Reservations**: An intuitive booking system for customers.
- **Image Gallery**: A beautifully animated showcase of the coffee shop experience.
- **Fast Performance**: Powered by Vite and optimized for speed.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **Linting**: [Oxlint](https://oxc.rs/docs/guide/usage/linter.html)

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/brew-bean.git
   cd brew-bean
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   Navigate to `http://localhost:5173` to see the application in action.

## 📁 Project Structure

```text
src/
├── assets/        # Static assets like images and icons
├── components/    # Reusable React components (UI, Layout, etc.)
├── data/          # Mock data for menus, gallery, etc.
├── lib/           # Utility functions and helpers
├── pages/         # Main page views (Home, Menu, Reservation, etc.)
├── App.jsx        # Root application component and routing
├── index.css      # Global styles and Tailwind directives
└── main.jsx       # React entry point
```

## 📜 Scripts

- `npm run dev` - Starts the Vite development server.
- `npm run build` - Builds the app for production to the `dist` folder.
- `npm run preview` - Locally preview the production build.
- `npm run lint` - Runs the Oxlint linter to check for code issues.
